01 / ABOUT

FFFilm 是什么

FFFilm 是面向影视拍摄规划的本地计算工具，提供数据率、存储容量、录制时长和快门换算功能，帮助你在拍摄前快速估算介质需求和曝光相关参数；Mac 版还内置胶片切片工作台，用于处理整条扫描。

数据率
根据相机、格式、分辨率、编码和帧率估算视频数据率。
存储规划
根据介质容量和拍摄时长估算每小时数据量、可录时长和每日总量。
快门换算
在不同拍摄帧率、项目帧率和理论快门角度之间进行换算，并提供频闪参考；灯光源支持市电 50/60 Hz、自定义光学频率，或 2–16 台显示器的刷新率组合。
胶片切片（仅 Mac）
导入 TIFF 或实验性 Flextight FFF 整条扫描，自动识别或手动框选片框，裁切、旋转拉直并排序后，导出 16 位 Adobe RGB TIFF 或 8 位 sRGB JPEG。原始扫描文件不会被修改。

02 / FAQ

常见问题

为什么计算结果与实际录制文件不同？

计算结果是规划估算。实际数据量可能受到摄影机固件、编码方式、拍摄内容、音频、文件封装和存储介质格式化容量等因素影响，请以实际设备测试和厂商说明为准。

FFFilm 会上传我的计算数据吗？

当前版本的核心计算在设备本地完成，不要求登录，也不会把计算输入、结果或本地偏好上传到开发者服务器。完整说明请查看隐私政策。

为什么 GB 和 GiB 的数值不同？

GB 使用 1000 进制，GiB 使用 1024 进制。FFFilm 的设置可以切换显示单位；码率、实际可录时长和容量占用百分比的计算逻辑不因此改变。

频闪参考快门是否保证现场不闪？

不能保证。参考候选基于输入的光学频率和理论模型；LED、PWM、滚动快门、电源波动和现场灯具差异都可能影响结果。请在实际灯光和摄影机组合下测试。

多台显示器场景下提示“折衷快门”是什么意思？

当 2–16 台显示器的刷新率组合不存在完全无频闪的快门角度时，FFFilm 会给出使各显示器频闪误差最小的折衷曝光参考，并标注每台显示器的剩余误差。这是理论最优解，不替代现场实测。

iPhone 或 iPad 上为什么没有胶片工作台？

胶片切片目前仅在 Mac 版提供：在 Mac 工具栏打开“胶片”标签（或按 ⌘3）。iPhone 和 iPad 版本提供完整的数据率与快门计算功能。

胶片切片会修改我的原始扫描文件吗？

不会。原始扫描只被读取；分帧、裁切和旋转等调整保存在你选择位置保存的 .fffilm 项目文件中，导出图像只写入你主动选择的文件夹。删除应用不影响原始扫描和已导出的文件。

为什么导入扫描时要求选择输入色彩配置？

未嵌入色彩配置的扫描无法被准确解释。FFFilm 会要求你指定扫描软件实际输出的色彩空间（如 sRGB、Adobe RGB），或提供匹配的 RGB ICC 文件；仅知道数据是线性的，不足以推断色彩原色。FFFilm 不做自动负片转换，色调调整请交给专业后期软件。

Flextight FFF 扫描支持到什么程度？

FFF 支持为实验性：已测试样本的 16 位 RGB 解码可用，但无法覆盖所有专有变体或校准过的扫描仪色彩；相机 RAW FFF 与 FlexColor 处理历史不受支持。请在自己的样本上验证后再纳入工作流。

FFFilm 支持哪些设备？

当前版本面向 iPhone、iPad 和 Mac，需要 iOS / iPadOS 18.6 或 macOS 15.6 及以上系统。相机目录中的规格与录制模式来自应用内置资料，不代表对某台摄影机全部固件或全部能力的穷尽说明。

03 / REPORT

提交问题时请附上

为了更快复现问题，请在邮件中尽量提供以下信息：

  • 应用版本：可在系统或 App Store 的应用信息中查看。
  • 设备与系统：例如 iPhone 17 Pro、iPad 或 Mac，以及对应的 iOS / iPadOS / macOS 版本。
  • 复现步骤：从打开应用到出现问题的具体操作顺序。
  • 当前设置：相机、模式、分辨率、编码、帧率、介质和拍摄时长等相关选项。
  • 胶片切片（如涉及）：扫描格式（TIFF 或 FFF）、导入与分帧的操作步骤、导出格式与质量设置，以及 .fffilm 项目能否正常重新打开。
  • 截图或录屏：如能帮助说明问题，请一并附上；请先移除不必要的个人或项目敏感信息。
